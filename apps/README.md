# Дастурамал: рӯйхати барномаҳо

Ин папка (`apps`) рӯйхати ҳамаи барномаҳои моро нигоҳ медорад. Аз он ду ҷо истифода мешавад:

1. **Сайт** — https://sulaimonzodaa.github.io — кортҳои барномаҳоро аз ҳамин ҷо месозад.
2. **Барномаҳо** (DiffSpot, Пазл ва ғ.) — бахши «Барномаҳои дигари мо»-ро аз ҳамин ҷо мегиранд.

Яъне барномаи навро **як бор** дар ин ҷо илова мекунед — он ҳам дар сайт ва ҳам дар ҳамаи барномаҳо пайдо мешавад. Нашри версияи нав дар Google Play лозим **нест**.

---

## Файлҳо

```
apps/
├── apps.json        ← рӯйхати барномаҳо (ном, тавсиф, нишона)
├── icons/           ← нишонаҳои барномаҳо
│   ├── muchal.webp
│   ├── shohnoma.webp
│   ├── diffspot_v2.webp
│   └── puzzle_v2.webp
└── README.md        ← ҳамин дастурамал
```

⚠️ Дар папкаи асосии сайт ба ин файлҳо **даст назанед**:

- `app-ads.txt` — барои AdMob зарур аст; бе он реклама даромад намедиҳад.
- `shohnoma/privacy.html` ва `shohnoma/delete-account.html` — Google Play ба онҳо ишора мекунад.

---

## Сохтори `apps.json`

Ҳар барнома як блок аст:

```json
{
  "package": "com.akmaljon.muchal",
  "name": { "tg": "Мучал", "ru": "Мучал", "en": "Muchal" },
  "icon": "icons/muchal.webp",
  "description": {
    "tg": "Тавсиф бо тоҷикӣ",
    "ru": "Описание на русском",
    "en": "Description in English"
  },
  "privacy": "shohnoma/privacy.html",
  "soon": true
}
```

| Майдон | Ҳатмӣ? | Маъно |
|---|---|---|
| `package` | ҳа | Номи пакети барнома дар Google Play (аз суроғаи саҳифа: `...details?id=`**`com.akmaljon.muchal`**) |
| `name` | ҳа | Номи барнома бо се забон |
| `icon` | ҳа | Роҳи нишона дар папкаи `apps` |
| `description` | не | Тавсиф бо се забон (танҳо дар сайт нишон дода мешавад) |
| `privacy` | не | Суроғаи саҳифаи сиёсати махфият (дар сайт тугма мешавад) |
| `soon` | не | `true` — барнома ҳанӯз нашр нашудааст (ниг. поёнтар) |

Тартиби блокҳо дар файл = тартиби барномаҳо дар сайт ва дар барномаҳо.

## 1. Илова кардани барномаи нав

1. Нишонаи барномаро омода кунед:
   - мураббаъ, аз **192×192** то **512×512** пиксел;
   - формат: `.png` ё `.webp`;
   - номи файл — бо ҳарфҳои лотинии хурд, бе фосила, масалан `chess.png`.
2. Дар GitHub ба папкаи `apps/icons` равед → **Add file → Upload files** → файлро кашед → **Commit changes**.
3. Файли `apps/apps.json`-ро кушоед → тугмаи ✏️ (**Edit**).
4. Пеш аз `]`-и охирин блоки навро илова кунед. **Ба вергул диққат диҳед:** пас аз `}`-и блоки қаблӣ вергул (`,`) бошад, пас аз блоки охирин — не.

   ```json
       },
       {
         "package": "com.akmaljon.chess",
         "name": { "tg": "Шоҳмот", "ru": "Шахматы", "en": "Chess" },
         "icon": "icons/chess.png",
         "description": {
           "tg": "...",
           "ru": "...",
           "en": "..."
         }
       }
     ]
   }
   ```

5. **Commit changes**-ро пахш кунед.

---

## 2. Барномаи ҳанӯз нашрнашуда (`"soon": true`)

Агар барнома ҳанӯз дар Google Play нест, ба блоки он `"soon": true,` илова кунед:

- дар **сайт** бо нишони «Ба зудӣ» намоён мешавад (тугмаи Google Play хира);
- дар **барномаҳо** пинҳон мемонад — то корбар ба саҳифаи холии Google Play наравад.

**Вақте барнома нашр шуд** — сатри `"soon": true,`-ро нест кунед. Ҳамин.

---

## 3. Иваз кардани нишона ⚠️

Барномаҳо нишонаҳоро дар телефони корбар нигоҳ медоранд, то ҳар бор аз интернет бор накунанд. Онҳо нишонаро **аз рӯи номи файл** мешиносанд.

**Агар файли навро бо ҳамон ном бор кунед** (масалан, `muchal.webp`-ро бо `muchal.webp`-и нав иваз кунед):

- дар сайт нишонаи нав мешавад ✅;
- дар барномаҳое, ки нишонаи кӯҳнаро аллакай бор кардаанд, **нишонаи кӯҳна мемонад** ❌ — чунки барнома мебинад «`muchal.webp` дар телефон ҳаст» ва онро дубора бор намекунад.

**Роҳи дуруст — ба файли нав номи нав диҳед:**

1. Нишонаи навро бо номи дигар бор кунед, масалан `muchal2.webp`.
2. Дар `apps.json` суроғаро иваз кунед:
   ```json
   "icon": "icons/muchal2.webp"
   ```
3. (Ихтиёрӣ) файли кӯҳнаи `muchal.webp`-ро нест кунед.

Барнома мебинад, ки `muchal2.webp` дар телефон нест, ва онро бор мекунад.

---

## 4. Иваз кардани ном ё тавсиф

Танҳо матнро дар `apps.json` иваз кунед ва **Commit changes**-ро пахш кунед. Қоидаи махсус нест.

---

## 5. Санҷиш пас аз ҳар тағйир

1. 1–2 дақиқа интизор шавед (GitHub Pages сайтро нав мекунад).
2. Кушоед: https://sulaimonzodaa.github.io/apps/apps.json — матни рӯйхат бояд намоён шавад.
3. Кушоед: https://sulaimonzodaa.github.io — кортҳо бояд намоён бошанд.

**Агар кортҳо нопадид шуданд** — эҳтимол дар `apps.json` хато ҳаст (аксар вақт вергули зиёдатӣ ё камбуд, ё нохунаки `"` фаромӯшшуда). Матни `apps.json`-ро ба https://jsonlint.com гузоред — он ҷойи хаторо нишон медиҳад.

Агар `apps.json` хато дошта бошад, барномаҳо вайрон **намешаванд**: онҳо рӯйхати охирини дурустро нишон медиҳанд.

---

## Барномаҳо рӯйхатро кай мегиранд?

- Ҳангоми кушодан, **на зиёда аз як бор дар 6 соат**. Яъне тағйироти шумо дар телефонҳо то 6 соат пас пайдо мешавад.
- Рӯйхат дар телефон нигоҳ дошта мешавад — бе интернет рӯйхати охирин нишон дода мешавад.
- Агар барнома ҳеҷ гоҳ ба интернет напайваст бошад — нусхаи дохилии рӯйхат нишон дода мешавад (он ҳангоми сохтани барнома дохил карда шудааст).
- Худи барнома дар рӯйхати худ нишон дода намешавад (масалан, дар DiffSpot — DiffSpot нест).
